Coding agents work best when they can **read the same notes you do**. Herdr gives every pane an `obs-herdr` CLI and an MCP server bound to this vault.

1. Keep long-running agents in a persistent Herdr session.
2. Hand them context straight from the note you are reading.
3. Review every edit in the Vault Control audit log, and undo with one click.
