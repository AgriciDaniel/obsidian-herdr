## Layout and interaction

- **Light and dark themes**: Zero hardcoded `#hex` colors and zero `!important` rules in `styles.css` (enforced by `esbuild.config.mjs`). Halftone dot-matrix surfaces use pure Obsidian CSS custom properties and `color-mix()`. `buildObsidianXtermTheme()` recomputes terminal foreground, background, cursor, selection (`--text-selection`), and distinct bright ANSI colors on `css-change` using the leaf's own `ownerDocument`/`defaultView`.
- **Narrow split panes**: `.herdr-dashboard-pane` declares `container-type: inline-size; container-name: herdr-pane;`. Below `380px`, `.herdr-mc-segmented` wraps to 2x2 and `.herdr-mc-kv` collapses cleanly to single column.
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` disables all pulse animations and panel hover transitions.
- **Declarative settings**: `HerdrSettingTab` renders settings via `getSettingDefinitions()`, keeps `vaultBridgeEnabled` and `vaultPermissionMode` synchronized, shares all 22 `SUPPORTED_AGENT_RUNTIMES`, and hides dependent UI-control sub-options when `allowUiControl` is off.
- **Remaining gap**: Automated unit tests and build gates do not substitute for human screen-reader (Orca / VoiceOver / NVDA) testing or live macOS/Windows desktop verification.
